Inteligência Artificial para Decisão

Ciências Econômicas e Administração · 2027-1

O curso apresenta os fundamentos de Large Language Models, embeddings, ferramentas computacionais, Retrieval-Augmented Generation, sistemas conversacionais e agentes. Cada aula combina exposição conceitual, resolução de problemas no papel e desenvolvimento aplicado por vibe coding.

Os alunos trabalham exclusivamente na interface gráfica do Codex, formulando prompts, verificando resultados e aperfeiçoando aplicações. O código Python é produzido pelo Codex. Não há programação manual nem atividade em terminal.

Organização

  • Programa e metodologia
  • Aulas 1 a 12
  • Caderno de exercícios conceituais
  • Dados e aplicações
  • Avaliações e quizzes
  • Bibliografia

Professor: Paulo C. Marques F.

As aplicações empregam dados didáticos e rotinas locais. Quando houver necessidade de geração por LLM dentro de uma aplicação, poderá ser usado o Codex Python SDK, somente após validação de autenticação e limites institucionais. O uso da API convencional da OpenAI não é requisito do curso.
