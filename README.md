# Inteligência Artificial para Decisão — Site Zensical

Disciplina do Insper, Ciências Econômicas e Administração, 2027-1. Responsável: Paulo C. Marques F.

## Conteúdo

- 12 capítulos teóricos aprofundados, com expressões matemáticas e exemplos;
- 12 apresentações em PDF, com fontes LaTeX;
- 120 exercícios resolúveis em papel;
- 12 laboratórios e 12 atividades feitas em casa, com novos dados;
- questões de treinamento, quizzes oficiais em pacote docente separado;
- provas-modelo PI/PF com gabaritos somente no pacote docente;
- casos sintéticos de Marketing Analítico, finanças, política monetária e atendimento.

## Publicação

Projeto-fonte do Zensical: `zensical.toml`, páginas em `docs/` e workflow GitHub Pages. Com Zensical instalado, executar `zensical build` (pelo professor ou automação; **não pelos estudantes**). A pasta `site/` é gerada e não deve ser misturada ao código-fonte.

**Prévia estática:** foi gerada uma versão HTML independente de Zensical na pasta `site_preview/` para inspeção sem build Zensical. Não é evidência de que o comando `zensical build` tenha sido executado neste ambiente.

### Acesso

Usuário: `inspirar`; senha: `pertencer`.

O formulário de acesso é um **bloqueio de interface em JavaScript**, não autenticação de servidor. O código e os materiais publicados continuam acessíveis a quem recebe o endereço do repositório ou dos arquivos. **Nunca publique provas oficiais, gabaritos, dados pessoais ou segredos de API nesse repositório.**

## Materiais docentes

As avaliações efetivas, rubricas e soluções ficam no **ZIP docente privado separado**, que não deve ser enviado a repositórios públicos. Os alunos desenvolvem aplicações apenas pela interface gráfica do Codex; a integração `openai_codex` requer validação institucional e não é garantida neste pacote.

## Dados

Todos os dados locais são didáticos/sintéticos, salvo identificação explícita. Documentos rotulados `copom/` não são atas oficiais. Não utilizar dados de mercados simulados para recomendações reais.
