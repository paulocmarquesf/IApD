# Bases didáticas do curso

**Todos os dados desta pasta são fictícios/sintéticos, gerados com seed 42.** Os relatórios e comunicados são elaborados para fins de ensino e não representam entidades ou decisões oficiais. Não usar para decisões reais.

`campanha_clientes.csv`: 480 clientes; variável resposta gerada por uma função logística com ruído; `respondeu` é o target (não incluir como feature).

`avaliacoes_rotuladas.csv`: 162 mensagens com rótulos e dois casos de prompt injection.

`catalogo_produtos.csv`: 16 produtos fictícios para busca lexical/semântica.

`cotas_fundos_simulados.csv`: 36 cotas mensais fictícias, normalizadas em 100.

`macro_simulada.csv`: 36 meses simulados, unidades indicadas no cabeçalho.

`campanhas_simuladas.csv`: receitas **atribuídas**; não demonstram impacto causal.

`relatorios/`, `comunicados/` e `faq/`: corpus controlado para RAG, com IDs e períodos explícitos.

`perguntas_rag.csv`: oito perguntas e documentos de referência, incluindo casos de abstenção.
