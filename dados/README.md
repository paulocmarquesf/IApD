# Dados didáticos

Todas as tabelas e documentos deste diretório foram criados para exercícios. **São sintéticos**; nomes de ativos, empresas, fundos e situações não devem ser confundidos com informações de mercado ou documentos oficiais. Para dados públicos, consulte as fontes relacionadas na página de referências do curso.

- `marketing_reviews.csv`: avaliações e perfis identificados para exploração semântica.
- `brands_market.csv`: posicionamento, preços e participação ilustrativos.
- `support_messages.csv` e `orders.csv`: triagem, políticas e processos.
- `prices_simulated.csv`: preços ajustados simulados de quatro ativos fictícios.
- `fundos/`: regulamentos fictícios de fundos.
- `copom/`: documentos fictícios de política monetária (não são atas oficiais).
- `politicas/`: políticas didáticas de atendimento.
- `golden_funds.csv`: referência documental, incluindo consulta não respondível.
- `agent_traces.json`: trajetórias para análise de agentes.

Semente de geração: 42. Não utilizar para decisões econômicas reais.
