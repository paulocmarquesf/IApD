# Glossário

**Agente:** sistema capaz de selecionar ações e ferramentas em função do estado e de resultados observados, sob restrições.  
**API:** interface para solicitar serviços programaticamente.  
**Chunk:** segmento de documento preparado para recuperação.  
**Codex CLI:** interface de linha de comando para delegar tarefas ao Codex.  
**Embedding:** representação vetorial de texto ou outro objeto.  
**Golden set:** conjunto de exemplos com referências verificadas.  
**Hit@k:** proporção de perguntas com resultado relevante nas primeiras k posições.  
**LLM-as-a-Judge:** avaliação de respostas por outro modelo de linguagem.  
**MRR:** média dos inversos dos postos dos primeiros itens relevantes.  
**Prompt injection:** tentativa de impor instruções por meio de conteúdo de autoridade inferior.  
**RAG:** recuperação documental usada como contexto para geração.  
**Saída estruturada:** objeto produzido segundo tipos e restrições definidos.  
**Tool calling:** solicitação feita por um modelo para que a aplicação execute uma ferramenta.  
**Workflow:** processo cujas transições foram especificadas antecipadamente.
