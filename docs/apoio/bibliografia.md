# Bibliografia selecionada

Selecionamos poucas referências que se complementam. A bibliografia é apoio para compreensão e aprofundamento; os materiais das aulas são autossuficientes para as avaliações.

## Bibliografia principal

1. **Huyen, Chip.** *AI Engineering: Building Applications with Foundation Models*. O'Reilly Media, 2025. Referência central para construir, testar e avaliar sistemas baseados em modelos fundacionais.
2. **Alammar, Jay; Grootendorst, Maarten.** *Hands-On Large Language Models: Language Understanding and Generation*. O'Reilly Media, 2024. Referência visual para embeddings, representações, transformers e recuperação.
3. **Jurafsky, Daniel; Martin, James H.** *Speech and Language Processing*. 3ª edição, manuscrito disponível online. Base conceitual de linguagem, representação e modelos de sequência.
4. **Fernandez, Pedro J.; Marques F., Paulo C.** *Data Science, Marketing & Business*. Versão 1.1. Referência para aplicações de concorrência, posicionamento e segmentação de mercado.

## Referência complementar

5. **Russell, Stuart; Norvig, Peter.** *Artificial Intelligence: A Modern Approach*. 4ª edição, Pearson, 2021. Fundamentos amplos de agentes e tomada de decisão.
