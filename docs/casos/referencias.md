# Aplicações locais de referência

As implementações a seguir são demonstradores determinísticos para inspecionar, executar e ampliar por prompts ao Codex. Não substituem a integração com a API ou o Codex SDK.

- `exemplos/marketing_competitivo.py`: seleção de concorrente e trilha de ferramentas.
- `exemplos/atendimento_workflow.py`: estado, prazos e autorização obrigatória.
- `exemplos/rag_local.py`: recuperação lexical e reescrita de consulta.
- `exemplos/portfolio_curva.py`: simulação de carteiras com retorno, risco, Sharpe e pesos.

Os arquivos ficam na raiz do repositório, em `exemplos/`, e utilizam somente a biblioteca padrão do Python. O aluno solicita ao Codex que execute ou adapte os exemplos; não escreve código manualmente.

O processamento local é suficiente para os exemplos mínimos. Para experimentar inferência com modelos, consulte [as duas rotas](../programa/codex.md).
