# Casos e dados

O material contém bases **sintéticas** destinadas ao ensino, inclusive preços, mensagens e documentos de fundos. Os arquivos na pasta `dados/copom/` são documentos didáticos fictícios e não devem ser apresentados como atas oficiais.

| Aplicação | Aulas | Dados principais |
|:--|:--|:--|
| Avaliações e marcas | 1, 2, 6 | `marketing_reviews.csv`, `brands_market.csv` |
| Atendimento e políticas | 3, 4, 10, 11, 12 | `support_messages.csv`, `orders.csv`, `politicas/` |
| Carteiras | 5 | `prices_simulated.csv` |
| Pesquisa documental | 7 | `copom/` (simulações) |
| Fundos de investimento | 8, 9 | `fundos/`, `golden_funds.csv` |

**Atividades em casa:** [pacote de dados para download](../dados/casa/) (navegue pela pasta de dados ou pelos links de cada aula). Em uma atividade avaliada, os dados serão congelados e identificados por versão.
